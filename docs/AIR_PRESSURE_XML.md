# AirPressure XML

`AirPressure::to_xml` and `load_air_pressure_str` preserve pressure Noise and
reference-altitude metadata. All seven Noise scalars and its kind are retained.
The standalone reader reuses existing document-node parsing, including effective
defaults and caller source locations. Output follows current typed fields without
mutating provenance. No atmospheric pressure, weather or noise sample is computed.

Matching standalone Sensor output preserves the existing envelope and raw pose.
Finite negative rates retain current metadata admission; the separate IMU rule
is unchanged. Plugins, extensions, gz_frame_id and mismatched families reject.
Joint XML stays force_torque-only, with explicit AirPressure rejection controls.
Existing parser policies and prior Noise/FT/IMU/Altimeter output are preserved.

Noise follows existing finite/non-subnormal and nonnegative-deviation rules.
Reference altitude must be finite and non-subnormal to survive the existing XML
numeric reader. Negative altitude and signed zeros are valid retained metadata.
These writer bounds do not claim complete native nonfinite/range parity.
