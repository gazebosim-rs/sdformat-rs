# AirSpeed XML

`AirSpeed::to_xml` and `load_air_speed_str` preserve pressure Noise kind and all
seven scalar fields through existing node parsing and numeric rules. Missing
pressure/noise keeps effective defaults; caller source locations are preserved.
Output follows current typed values without mutating input provenance. No
pressure-to-speed conversion, wind, atmosphere or noise sample is computed.

Matching standalone air_speed Sensor output keeps current envelope metadata and
raw pose. Plugins, extensions, gz_frame_id and mismatched families reject. Joint
XML stays force_torque-only, with explicit AirSpeed reader/writer rejection tests.
Finite negative rates retain existing metadata admission; IMU's separate rate
restriction is unchanged. Shared Noise and existing serializer output is preserved.

Existing output bounds require finite/non-subnormal Noise scalars and nonnegative
standard deviations, including bias/dynamic deviation. Signed zeros and negative
mean/bias/correlation/precision metadata remain representable. Complete native
nonfinite/range parity and runtime measurement remain separate work.
