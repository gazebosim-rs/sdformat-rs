# Altimeter XML

`Altimeter::to_xml` and `load_altimeter_str` preserve vertical-position and
vertical-velocity Noise records. Each includes kind and all seven scalar fields.
The standalone loader reuses existing document-node parsing; omitted groups
retain existing effective defaults. Explicit loading retains the caller's source
location. Output uses current typed fields without mutating input provenance.
No height, velocity, atmosphere or noise sample is computed.

Matching standalone Sensor output now supports altimeter with the existing
name, frame/topic, raw quaternion pose/frame, rate and envelope flags. Unresolved
frames remain metadata. Finite negative Altimeter rates retain the existing
unthrottled metadata policy; the separate IMU negative-rate restriction is
unchanged. Plugins, extensions, gz_frame_id and mismatched families reject.
Joint XML remains force_torque-only, including a new Altimeter rejection control.
The document parser and shared Noise/FT/IMU output policies remain unchanged.

The writer applies existing Noise rules: finite non-subnormal numbers and
nonnegative standard deviations (including bias and dynamic deviation). Negative
means, bias means, correlation times and precision remain permitted metadata.
Signed zeros are emitted and retain their bits. These bounds are existing owned
reader/writer policy, not a claim of complete native nonfinite/range parity.

## Native evidence and exact original mapping

Sixteen actual native cases cover defaults, omitted channels, all three Noise
kinds, distinct channel values, all seven scalar fields, signed zeros, finite
extremes, two invalid numeric states and three standalone sensor envelopes.
Fourteen actual Rust XML outputs load in the native library. Non-pose projections
compare exact bits; sensor pose components retain direct signs and <=1e-3 bounds.
The native-generated original fixture is checked in and regenerated byte for
byte. Source/library identities and commands are in reference/altimeter-xml.json.

```
python3 tools/altimeter_xml_reference.py /path/to/pinned/sdformat
cargo test --locked --test altimeter_xml --test altimeter_xml_original
```

Both unchanged native DOMAltimeter.ToElement originals pass with empty stderr.
Their Rust ports keep default Noise assertions before edits, both complete
configured Noise observations, successful nonempty output and reload, and the
edited position-noise result. Exact finite Noise equality strengthens the native
component-wise <=1e-6 comparisons. ErrorOutput runs in the independently reviewed
quiet child helper, admitting only successful libtest protocol on stdout and
requiring empty stderr.

The coordinator-approved constructor-input translation observes source.is_none() after
immutable output: no loaded input declaration was fabricated. This addresses
only Altimeter_TEST.cc:125,179 constructed Element()==nullptr assertions. These
two originals have no loaded Element identity assertion. This is not a general
Source/Element equivalence, pointer/ownership or mutation contract. Independent
source/original review approved this exact complete mapping, without extending
it to loaded identity or other originals.

Author checks pass all 446 Rust tests, formatting and Clippy. Shared helpers
replay all 32 force/torque and 24 IMU native cases; all six prior force/torque
and four prior IMU exported XML outputs remain byte-identical. Independent review
