# Magnetometer XML

`Magnetometer::to_xml` and `load_magnetometer_str` preserve X/Y/Z Noise records,
each with kind and all seven scalars. Loading reuses existing XYZ-node parsing,
now extracted for standalone use: omitted groups/axes retain effective defaults,
unknown children still reject, and caller locations are preserved. Existing
Noise numeric admission is unchanged. No magnetic field or noise sample is
computed, and no vector is normalized.

Matching standalone Sensor output preserves the current envelope and raw pose.
Finite negative rates keep their existing metadata meaning; IMU keeps its separate
rate restriction. Plugins, extensions, gz_frame_id and mismatched families reject.
Joint XML remains force_torque-only, with explicit Magnetometer reader/writer
rejection controls. Shared Noise and existing family serializers are unchanged.

All output Noise numbers must be finite and non-subnormal, with nonnegative
standard deviations (including bias/dynamic deviation), matching existing writer
policy. Signed-zero bits and negative mean/bias/correlation/precision metadata
are retained. Native nonfinite/range behavior remains separately unqualified.

## Native and original evidence

Seventeen actual native cases cover defaults/omitted axes, all three Noise kinds,
distinct axis values, every scalar, signed zeros, finite extremes, invalid X/Z
numbers and three Sensor envelopes. Fifteen actual Rust outputs load in native
Magnetometer/Sensor. Non-pose projections compare exact bits; sensor quaternion
components keep direct signs and <=1e-3 bounds. The native-generated original
fixture is regenerated byte for byte. Provenance and commands are in
reference/magnetometer-xml.json.

```
python3 tools/magnetometer_xml_reference.py /path/to/pinned/sdformat
cargo test --locked --test magnetometer_xml --test magnetometer_xml_original
```
